# LegacyCraft — External Reference Sources (Tier 2–3)

Compiled while reviewing the master context doc. These are documentation/reference
*sources*, not bundled assets — per the master doc's clean-room IP policy (§2), no
Mojang textures/sounds/models should be downloaded or redistributed as project files.
Use these for behavioral research and as citations in `verified_facts.md` /
`bugs_1_8_9.yml`, not as asset sources.

## Version facts (Tier 1/3)
- [Java Edition 1.8.9 – Minecraft Wiki](https://minecraft.wiki/w/Java_Edition_1.8.9) —
  confirms release date **Dec 9, 2015**, protocol **47**, and that changes from 1.8.8
  were minor: Realms notification toggles, 13 bug fixes (water physics, village
  spawning, arrow despawning, chat formatting, skin rendering), and a fun quirk —
  trapped chests render Christmas textures Dec 24–26 (a genuine dated Easter egg,
  candidate for the bug/quirk registry §19.1 / §88 if the project wants full fidelity).
- [Java Edition version history – Minecraft Wiki](https://minecraft.wiki/w/Java_Edition_version_history)
- [Version history – Minecraft Wiki](https://minecraft.wiki/w/Version_history)

## Protocol 47 (Tier 2)
- [wiki.vg Protocol](https://wiki.vg/Protocol) — historical protocol doc; wiki.vg's
  content was merged into minecraft.wiki's Projects namespace. Use an *archived*
  revision from late 2015/early 2016 (via Wayback Machine) rather than the live page,
  since the live page now documents current protocol versions, not 47.
- [Protocol version numbers – Minecraft Wiki](https://minecraft.wiki/w/Minecraft_Wiki:Projects/wiki.vg_merge/Protocol_version_numbers)
- [Internet Archive: wiki.vg 2017-10-15 dump](https://archive.org/details/wikivg-20171015-wikidump.7z) —
  a full wiki.vg snapshot; useful as a stable, dated reference point.

## Resource pack format (Tier 3)
- [Pack format – Minecraft Wiki](https://minecraft.wiki/w/Pack_format) — confirms
  `pack_format: 1` covers 1.6.1–1.8.9 (anvil-era, pre-flattening).
