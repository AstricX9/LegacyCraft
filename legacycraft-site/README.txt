LegacyCraft website (plain HTML/CSS/JS, no framework or build step)

  index.html        homepage: world flyover, news, dev log
  download.html     download page: one section per platform, Java 17 help
  css/global.css    colours, page/header textures, layout, headings, footer (every page)
  css/elements.css  reusable bits: orange button, notes, code, download lists (every page)
  css/home.css      homepage only
  css/download.css  download page only
  js/home.js        homepage flyover + "Site textures" picker
  js/downloads.js   download links (set VERSION here when you release)
  assets/           images, see assets/README.txt
  downloads/        put the package zips here, see downloads/README.txt

Open index.html in a browser, or serve the folder from any static host.
