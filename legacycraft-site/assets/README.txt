Site images read by index.html:
  icon.png        - browser tab icon (square; 32x32 or 16x16)
  header.png      - header bar tile (square, 16x16 recommended)
  background.png  - page background tile (square, 16x16 recommended)
  animals.png     - picture above the download button (up to 240px wide; hidden if missing)
Missing tiles fall back to the built-in generated textures.
