to a new world.

You’ll need Git, JDK 17 or newer, and a graphics driver with OpenGL support.

Full setup guide ↗
01

Get the source.

Clone the project and open its folder.

git clone https://github.com/AstricX9/LegacyCraft.git cd LegacyCraft
02

Add your resource files.

The repository does not include Minecraft’s textures, sounds or other assets. Follow the resource setup guide to add a local copy you’re entitled to use.

On Windows, the included fetch-mc-assets.bat helper can set up the resource folder.

03

Step into the game.

Run the Gradle Wrapper for your system.

Windows PowerShell.\gradlew.bat run
macOS / Linux./gradlew run

Gradle downloads the build dependencies on the first run.

03 / A little help

Before you head out.

A few things to know about the current build.

Which Java version do I need?

Use JDK 17 or newer to run from source. Packaged builds need Java 17 or newer. Get Temurin 17 ↗

A package can also use a Java runtime placed in its runtime/ folder. See the Windows or macOS and Linux package guide for the folder layout.

Is everything from 1.8.9 implemented?

Not yet. LegacyCraft targets the observable behaviour of Minecraft 1.8.9, but some mechanics and compatibility features are incomplete. The known differences are tracked in the repository.

The game won’t open. Where do I start?

Check that Java 17 or newer is installed and the resource files are in place. For OpenGL errors, install a current graphics driver from your hardware manufacturer.

When running from source, the terminal contains the game’s output. Include the error and your platform when reporting an issue.

Can I build a package myself?

With JDK 17 installed, run build.bat on Windows or ./build.sh on macOS or Linux. Packages are written to build/distributions/. See the build guide for platform tasks and requirements.
