Download

LegacyCraft is free. Each download is a zip with the launcher and the game already built, so there's nothing to compile and no account to make. Unzip it anywhere and start the launcher. You'll be able to play without an Internet connection.

Current version: a1.0.1 (Minecraft 1.8.9 behaviour).

You need Java 17

LegacyCraft runs on Java 17 or newer. If you already have it installed, you're done. If not, you don't have to install anything: put a copy of Java in the LegacyCraft folder and the launcher finds it there.

  1. Go to Temurin 17 at adoptium.net and pick your system, the same architecture as the zip you downloaded (x64, x86 or aarch64), and the JRE archive (.zip on Windows, .tar.gz on Mac and Linux).
  2. Unpack it into the LegacyCraft folder and rename the folder it makes to runtime.

That gives runtime\bin\javaw.exe on Windows, runtime/bin/java on Linux or runtime/Contents/Home/bin/java on a Mac.

LegacyCraft for Windows

Download and unzip LegacyCraft-windows.zip 64- and 32-bit, Windows 7 SP1 or later. Then double-click LegacyCraft Launcher.bat and press Play. Play LegacyCraft.bat starts the game straight away without the launcher.

This one zip works on every Windows PC, old or new, and picks the right files for your system. On 32-bit Windows the game is limited to 1 GB of memory.

LegacyCraft for Windows (alternative)

If you'd rather have a smaller download for just your system, there's 64-bit, 32-bit and ARM64 (Surface and other Snapdragon PCs). To see which Windows you have: Start, right-click Computer, Properties, "System type". They run the same way as the one above.

LegacyCraft for macOS

Download LegacyCraft-macosArm64.zip for Apple silicon (M1 and newer) or LegacyCraft-macosX64.zip for Intel Macs. Unzip it, open Terminal in that folder and run:

./launcher.sh

If macOS refuses to open a downloaded file, run xattr -dr com.apple.quarantine . in the folder once.

LegacyCraft for Linux

Download LegacyCraft-linuxX64.zip (most PCs) or LegacyCraft-linuxArm64.zip (ARM, like a Raspberry Pi 4 or 5). Unzip it and run ./launcher.sh, or ./play.sh to skip the launcher. Any Java 17 on your PATH or in JAVA_HOME works.

Build it yourself

Every package above is made from the source on GitHub. With a JDK 17 installed, run build.bat (Windows) or ./build.sh (Linux and macOS) for a menu, or call a Gradle task directly:

gradlew packageWindows # or packageLinuxX64, packageMacosArm64, packageAll ...

The zips land in build/distributions/, named LegacyCraft-<version>-<platform>.zip. The version comes from version.txt.

If the game won't start

  • "Needs Java 17": see You need Java 17 above.
  • The window doesn't open, or there's an OpenGL error: update your graphics driver from NVIDIA, AMD or Intel. The drivers Windows installs by itself often don't include proper OpenGL.
  • Out of memory on 32-bit Windows: keep the instance's memory at 1024 MB or less in the launcher.
  • The launcher's Launcher Log tab shows everything the game printed.

Your settings and instances are kept in .legacycraft-launcher in your home folder, so a new download keeps your worlds.
