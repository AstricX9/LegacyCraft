Download / setup

Project version: a1.0.2. Current target: 1.9.

The game is still in development. The launcher and packaged builds are early prototypes. Running from source is the current development setup.

On this page: Source setup · Packages · Java · Help

Run from source

You need JDK 17 or newer, Git and a graphics driver with OpenGL support.

  1. Get the repository:
    git clone https://github.com/AstricX9/LegacyCraft.git
cd LegacyCraft
  2. Add the Minecraft resource files for the build you’re running. Use a copy you’re entitled to use; the repository does not supply these assets. See the resource setup instructions in the README.
  3. Run the client:

    Windows PowerShell:

    .\gradlew.bat run

    Linux / macOS:

    ./gradlew run

The first run downloads the build dependencies. Full instructions in the README.

Build your own package

With JDK 17 installed, run build.bat on Windows or ./build.sh on Linux / macOS. The ZIPs go in build/distributions/. See the build instructions for individual platform tasks.

Java

Use JDK 17 or newer to build from source. Packaged builds need Java 17 or newer. Temurin downloads.

A packaged build can also use a Java runtime in its runtime/ folder. The package guides above explain the folder layout.

If it won’t start

  • Check your Java version and resource files first.
  • For OpenGL errors, check the graphics driver from your hardware manufacturer.
  • When running from source, look for the error in the terminal. Packaged launcher builds have a Launcher Log tab.
  • If you get stuck, open an issue with the error and your operating system.

Some mechanics and compatibility features are still incomplete. See the known differences.
