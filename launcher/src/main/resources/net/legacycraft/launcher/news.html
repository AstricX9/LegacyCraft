LegacyCraft 1.8.9

An offline launcher for a from-scratch recreation of Minecraft 1.8.9.

Instances

Each instance is its own copy of the game: its own worlds, resource packs, options and server list, kept in its own folder, with its own memory, window size and Java settings.

+ Make a new instance for a fresh start
+ Copy an instance to try something out without touching your worlds
+ Pick the instance to play at the bottom left, then press Play

Skins and capes

Choose what you wear without leaving the launcher. Add any 64x64 skin (or an old 64x32 one), pick Classic or Slim arms, add 64x32 capes, and spin your player around in the preview. Steve and Alex are always there if you want to go back.

About 1.8.9

No account is needed: use Change name to pick the name you play with. What the game prints shows up in the Launcher Log.
