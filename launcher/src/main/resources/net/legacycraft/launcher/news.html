Bring your worlds along

Got a world from Minecraft 1.8.9? Open the Worlds tab and press Import World Folder (or Import .zip, or drop it onto the list). It's copied into your saves, never over an existing world, and the game converts it the first time you open it. Chest contents, sign text and mobs don't come along yet.


Skins and capes in the launcher

You can now choose what you wear without leaving the launcher!

+ Add any 64x64 skin, or an old 64x32 one
+ Choose Classic or Slim arms for each skin
+ Add capes (64x32, like the official ones) and wear them in game
+ Spin your player around in the preview
* Steve and Alex are always there if you want to go back

Open the Skins & Capes tab to try it out, enjoy!


Profiles

Each profile can have its own game directory, window resolution, launcher visibility and Java arguments. Use New Profile and Edit Profile at the bottom of the window.

No account is needed: press Switch User to pick the name you play with.


LegacyCraft 1.8.9

LegacyCraft is a from-scratch recreation of Minecraft 1.8.9. Press Play to start it; what the game prints shows up in the Launcher Log tab.
